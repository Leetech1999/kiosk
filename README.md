# kiosk (React)

## 프로젝트 소개  
병원 안내 키오스크용 웹 애플리케이션으로, 각 층별 안내와 부서 위치를 SVG와 React 상태 관리로 동적으로 표시합니다.

## 주요 기능  
- 층별 안내 컴포넌트  
- SVG 기반 시각적 위치 표시  
- 반응형 웹 및 접근성 고려

## 사용 기술  
React, SVG, CSS
